# Seminorm-envelope map (exploratory)

2026-11-06, branch `pulp-fiction`. Method, proofs of the bounds and scope: [docs/seminorm_envelope.md](../../docs/seminorm_envelope.md).

Every value is the relaxed depth-one gap (D1-B)/L over all symmetric-loss seminorms satisfying the game constraints, maximized by grid search plus local refinement. It is an upper bound on what demand laws can realize; realizability is not checked. Equality with a proved bound certifies the relaxation's value. A value strictly below every proved bound is a numerical observation.
